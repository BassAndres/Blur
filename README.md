# Herramientas

Scripts y utilidades de trabajo. Cada herramienta vive en su propia carpeta con su
propio `LEEME.md`.

| Carpeta | Qué hace |
|---|---|
| [`sds_basf/`](sds_basf/) | Descarga las SDS (español, variante MX, org. D016) desde el portal de BASF y genera `reporte.csv`. |
| [`nuup_etiquetas/`](nuup_etiquetas/) | (En desarrollo) Descarga la última etiqueta comercial (Commercial Labels) de cada producto en NUUP (Veeva Vault). |
| [`horario/`](horario/) | Genera el horario 2027-1 (UNAM) en CSV para importarlo a Google Calendar. |
